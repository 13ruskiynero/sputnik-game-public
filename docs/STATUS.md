# Статус прототипа

Дата проверки: 2026-10-17.
Среда: Chromium 156 headless (Playwright), WebGL через SwiftShader,
viewport 1280x800 и 390x844. Отдельно проверена сборка GitHub Pages.

## Что проверено

- Страница загружается без ошибок JavaScript.
- WebGL доступен, сцена рендерится: 26 684 треугольника, 14 draw calls.
- Текстура Земли загружена (2048x1024).
- 5 кликов по «Действию» дают ровно $1, полоса действия сбрасывается.
- Вращение Земли мышью меняет rotation; синтетические Pointer Events
  (pointerType touch) также вращают глобус.
- Контракт: при совпадении спутника и зоны (угол ~0) снимок засчитывается,
  награда +$10, счётчик контрактов увеличивается, создаётся новый контракт.
- Магазин: покупка спутника связи за $25 уменьшает баланс, добавляет второй
  аппарат в сцену, включает доход +$0.05/сек.
- Пассивный доход начисляется: +$0.06 за 1.3 секунды.
- Выбор спутника через панель «Спутники» переключает активный аппарат.
- При энергии ниже 15 кнопка «Действие» визуально неактивна, клик показывает
  сообщение «Мало энергии — дождитесь солнечной стороны».
- Мобильная раскладка 390x844: кнопки в пределах экрана, горизонтальной
  прокрутки нет.
- GitHub Pages: https://13ruskiynero.github.io/sputnik-game-public/ —
  приложение загружается, текстура и Three.js подхватываются, 5 кликов дают $1,
  ошибок в консоли нет.

## Что пока условно

- Контракт один, без срока выполнения; после выполнения сразу создаётся новый.
- Спутник связи только даёт пассивный доход и не участвует в контрактах.
- Орбиты упрощённые, без физики; скорость и наклон заданы константами.
- Освещённость считается по положению спутника относительно направления
  на Солнце; температура и деградация панелей не моделируются.
- Экономика настроена грубо: $1 за 5 кликов, $10 за контракт, $25 за связь.
- Нет звука, анимации запуска и выбора орбиты.
- Реальный touch в headless Chromium не эмулируется через CDP; проверены
  Pointer Events и мобильная раскладка. На устройстве используется тот же
  pointer-обработчик.

## Известные вопросы

- Темп первых 5 кликов может оказаться медленным — нужно проверить в игре.
- Зона контракта может оказаться на обратной стороне Земли; игрок вращает
  глобус, но нужна подсказка направления.
- Стоит добавить индикатор «спутник над зоной» на самой сцене, а не только
  в карточке контракта.
- Игра на телефоне открывается через GitHub Pages; локальный сервер нужен
  только для разработки.

## Как запустить

```
cd /root/projects/sputnik_game
python3 -m http.server 8099
```

Открыть `http://localhost:8099/`.

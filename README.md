# Игра про спутники — sputnik-game

Рабочее название проекта. Идея выросла из кейса КосмоХакатона
«Автономное управление спутниковой группировкой» (Благовещенск, сентябрь 2026).

Статус: каркас. Концепт и механика в разработке — см. `docs/BRIEF.md`.

## Репозитории

- **Основной (приватный):** https://github.com/13ruskiynero/sputnik-game
- **Публичное зеркало (для ChatGPT):** https://github.com/13ruskiynero/sputnik-game-public

Зеркало содержит только файлы, разрешённые для внешнего чтения: документацию,
исходники и ассеты. Секреты, окружения и тяжёлые бинарники исключаются.

## Структура

```
docs/      бриф, дизайн-документы, решения
src/       исходный код игры
assets/    графика, звук, данные
tools/     служебные скрипты (публикация зеркала)
```

## Публикация зеркала

```
tools/sync_public.sh --dry-run   # показать, что попадёт в зеркало
tools/sync_public.sh --push      # собрать, проверить на секреты и запушить
```

Зеркало — снимок (snapshot), приватная история в него не переносится.
